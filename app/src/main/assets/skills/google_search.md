# Google Search
> Search anything on Google and return results
Trigger: search, google, find, look up

## Instructions
When asked to search Google:
1. OPEN_APP com.android.chrome
2. TAP the address bar
3. TYPE the search query
4. Press Enter / TAP the search button
5. Wait for results to load
6. Read the top 3 results from the screen
7. DONE — report back the results found

## Examples
- "Search for tiffin services in Wakad Pune"
- "Google current petrol price in Pune"
- "Look up n8n automation tutorials"
