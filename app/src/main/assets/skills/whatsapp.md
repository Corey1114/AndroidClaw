# WhatsApp Messaging
> Send messages on WhatsApp to any contact
Trigger: whatsapp, message, send message, wa

## Instructions
When asked to send a WhatsApp message:
1. OPEN_APP com.whatsapp
2. Wait for home screen to load
3. TAP the search/new chat icon
4. TYPE the contact name
5. TAP the correct contact from results
6. TAP the message input field
7. TYPE the message
8. TAP the send button
9. DONE — report success

## Examples
- "Send WhatsApp to Rahul: I'll be late by 30 minutes"
- "Message Mom on WhatsApp: Coming home for dinner"
- "WhatsApp Priya: Meeting postponed to 4pm"

## Notes
- Contact names are case-insensitive
- If contact not found, scroll down in search results
- Message field is at the bottom of the chat screen
